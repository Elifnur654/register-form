# 🚀 Modern JavaScript Form Validation Project

A modern, responsive, and user-friendly registration form validation project built using HTML5, CSS3, and modern JavaScript.

## 📌 Features

* **Dynamic Validation:** Real-time error and success feedback for username, email, phone number, and password fields.
* **Custom Phone Number Validation:** Checks if the phone number consists of exactly 11 digits and contains only numbers.
* **Password Matching:** Security check to ensure that the password and confirm password fields match.
* **Responsive Design:** Clean and adaptive interface designed for various screen sizes.

## 🛠️ Built With

* **HTML5** - Markup and structural layout
* **CSS3** - Flexbox, CSS Variables, and custom success/error state styling
* **JavaScript (ES6+)** - DOM manipulation, regex email checking, and custom validation functions
